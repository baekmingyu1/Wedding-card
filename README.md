# 모바일 청첩장

서버 없이 동작하는 정적 청첩장입니다. `index.html`을 브라우저에서 열어 미리 볼 수 있습니다.

## 내용과 사진 바꾸기

`content.js`에서 이름, 예식 정보, 초대글, 지도 링크, 계좌 정보를 수정합니다. 값이 확정되지 않은 버튼은 비활성화됩니다.

오프닝은 `content.js`의 `openingPhotos`에 적힌 사진 수에 맞춰 동작합니다. 현재는 `DSC09569.jpg`부터 `DSC09583.jpg`까지의 **15장**을 파일명 순서대로 연결했습니다. 스크롤에 따라 사진이 한 장씩 전환되어 신랑이 다가가는 장면을 보여줍니다. 사진이 없거나 불러오지 못하면 자리 표시 화면이 나타납니다.

첫 사진 위에서 문구가 먼저 사라집니다. 문구가 사라진 다음에도 첫 사진을 잠시 보여주고, 이후 스크롤부터 15장의 움직임이 시작됩니다.

모바일에서도 사진이 배경처럼 화면을 채우고 문구가 그 위에 나타납니다. 가로 사진의 전체 장면을 유지하기 위해 화면 주변은 같은 사진을 흐리게 확장하며, 모든 장면은 같은 위치에 고정됩니다.

원본 JPG는 `assets/opening/`에 보관하고 Git에서는 제외합니다. 웹용 사본은 `assets/opening/frames/01.webp`부터 `15.webp`까지이며, 공개되는 저장소에는 이 최적화된 사진이 포함됩니다. 사진을 추가하거나 순서를 바꾸면 웹용 사본과 `openingPhotos` 목록을 함께 수정하세요.

사진첩은 `assets/gallery/`에 사진을 넣고 `galleryPhotos`의 경로를 바꾸면 됩니다. 세로 사진을 권장하며, 웹에 맞게 크기와 용량을 줄여 주세요.

## 배포

빌드와 서버가 필요하지 않습니다. `index.html`, `styles.css`, `script.js`, `content.js`, `assets/`를 함께 정적 호스팅에 올리면 됩니다. CSS와 JavaScript는 상대 경로를 사용합니다.

## 확인할 화면

- 작은 모바일 화면에서 가로 스크롤이 없는지
- PC와 모바일에서 우측 목차 버튼으로 각 구역에 이동하는지
- 사진을 넣은 뒤 스크롤에 따라 오프닝 순서가 맞는지
- 지도와 복사 버튼이 확정된 정보에만 활성화되는지
