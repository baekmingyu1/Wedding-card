# 청첩장 디자인 기준

2026-10-14. 사용자가 선택한 아이보리·세이지 그린으로 따뜻한 청첩장 분위기를 만들고, 앱의 명확한 정보 구분과 직접 선택하는 조작 방식을 적용한다.

## 색상과 배경

- 바탕 `#f4f2eb`, 밝은 카드 `#fffdf9`, 보조 영역 `#e8eee3`.
- 본문 `#29352f`, 보조 글자 `#646d65`, 주요 동작·선택 상태 `#486653`.
- 초대 문구는 넉넉한 여백에 두고, 달력·D-DAY·계좌·교통 정보에는 22~28px 둥근 면을 사용한다.
- 사진은 인트로와 갤러리에만 배치한다. 위치 안내용 지도는 기능 정보로 유지한다.
- 갤러리는 3열, 페이지당 9장이다. 주요 버튼은 짙은 그린, 보조 버튼은 밝은 면으로 구분한다.

## 참석 응답

구분·참석 여부·식사 여부는 드롭다운 대신 네이티브 라디오 입력을 버튼 형태로 표시한다. 한 번 눌러 선택할 수 있으며 선택 상태는 배경·테두리·체크 표시로 구분한다. 키보드 방향키와 필수 입력 검증을 유지한다. 참석을 선택한 경우에만 인원·식사 항목을 활성화하고, 불참일 때는 해당 값을 전송하지 않는다. 실제 제출은 사용자가 전달 버튼을 눌렀을 때만 수행한다.

## 참고한 공식 디자인 자료

- [Material Design — Color roles](https://m3.material.io/m3/pages/color-roles?s=m3): 바탕과 카드의 명도 차이로 계층을 표현하는 원칙을 참고했다.
- [Apple — New software design](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/): 둥근 조작 요소와 콘텐츠 중심 구성의 참고 자료다. 이 사이트에는 투명 유리 효과를 추가하지 않았다.

아이보리·세이지 배색은 이 청첩장에 맞춘 디자인 선택이며, 특정 연도의 유일한 유행색이라는 의미가 아니다.

## 명암비

WCAG 상대 휘도 공식으로 계산했다. 사진 위 글자와 모든 상태를 포함한 접근성 인증을 뜻하지 않는다.

| 글자색 | 밝은 카드 | 아이보리 바탕 | 옅은 그린 |
| --- | --- | --- | --- |
| 본문 | 12.57:1 | 11.40:1 | 10.81:1 |
| 보조 글자 | 5.28:1 | 4.79:1 | 4.54:1 |
| 그린 포인트 | 6.26:1 | 5.68:1 | 5.38:1 |

모션 감소 설정, 가운데 정렬, 사진의 원래 비율, 기존 예식 정보와 참석 응답 전송 형식을 유지한다. 새 이미지나 UI 라이브러리는 추가하지 않는다.
